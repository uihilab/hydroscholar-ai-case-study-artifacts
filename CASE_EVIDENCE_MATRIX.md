# HydroScholar AI Directed-Graph Study Case-Evidence Matrix

## Purpose and scope

This matrix documents the evidence retained for the five author-run workflow scenarios associated with the HydroScholar AI directed-graph study. It is an evidence map, not a performance table. Event counts describe preserved records; they are not success rates. The matrix supports a bounded engineering claim about typed workflow execution, retained provenance, inspection, recovery, and documented limitations. It does not establish independent replication, uniform completion, aggregate performance, comparative effectiveness, or hydrologic validity.

Use the paths below together with `MANIFEST.csv` to inspect the released artifacts. This file becomes a citable case-evidence matrix only after a versioned repository release is archived with a persistent identifier.

## Reading the matrix

`Observed behavior` reports what the preserved record permits an evaluator to inspect. It is not a statement that each workflow completed successfully or that its scientific result is correct. `Documented limitation` identifies the boundary on the corresponding observation. The folder-level `ARCHIVE_README.md` files and repository-level `MANIFEST.csv` list the package exclusions.
